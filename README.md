# GeoBox Player

Mac miniから1系統の4K映像を送出する、macOS向けSwiftアプリです。
プロジェクト → 映像／音声プレイリスト → トラックの構成で管理します。

- 開発環境：Xcode 16以降／Swift 6以降
- 対応OS：macOS 14以降
- 仕様：[REQUIREMENTS.md](REQUIREMENTS.md)

## 開発

Xcodeで`Package.swift`を開き、GeoBoxPlayerを実行します。

```sh
swift test
swift run GeoBoxPlayer
```

Codexの制限された環境でビルドする場合は、SwiftPMのマニフェスト用サンドボックスとの二重適用を避け、キャッシュを作業フォルダに置きます。

```sh
CLANG_MODULE_CACHE_PATH="$PWD/.build/module-cache" swift test --disable-sandbox --cache-path .build/cache --config-path .build/config --security-path .build/security
```

## アプリの作成・操作

```sh
./scripts/build-app.sh
open "dist/GeoBox Player.app"
```

生成先は`dist/GeoBox Player.app`です。ローカル実行用のアドホック署名を行います。

1. プロジェクト設定で映像出力先と送出リフレッシュレート、音声出力先を選びます。
2. 左側の作成ボタンで映像・音声プレイリストを作成します。
3. Finderからファイルをトラック一覧へドロップします。
4. 「スケジューラ設定」を開き、左のプレイリストをカレンダーの再生日時へドラッグします。開始・終了日時、開始・終了フェードを編集して保存します。トラック行の再生ボタンで手動確認できます。
5. 画面をロックすると時刻再生のみになり、手動再生・編集を禁止します。

プレイリストページの「トラック間の再生設定」で、映像・音声それぞれのIN／OUTと映像フェード先をプレイリストごとに設定できます。既存プロジェクトの共通設定は、読み込み時に各プレイリストへ引き継ぎます。

画像トラックの「画像表示時間」は、「時間・分・秒」をそれぞれの欄に入力できます。例えば「0時間・1分・30秒」で90秒になります。秒は小数にも対応します。設定範囲は0.1秒〜7日間（168時間）です。従来の上限1時間のプロジェクトも、読み込み時に上限を7日間へ更新します。

トラックにマウスを重ねると再生ボタンが表示されます。ロック解除中にクリックすると、そのトラックの先頭から割り込み再生し、終了後は同じプレイリストの次のトラックへ進みます。再生中のトラックをクリックすると先頭から再生し直します。

右クリックで削除・複製・コピー・ペースト・Cut、Deleteキーで登録削除、ドラッグで再生順序を変更できます。コピー・Cut・ペーストはCmd+C/X/V、複製はCmd+D、取り消しはCmd+Zです。メディア実体は削除しません。

[実装・検証記録](docs/IMPLEMENTATION.md)に運用ルール、対応確認済み素材と実機検証が必要な項目をまとめています。映像コーデックのテストはmacOSの映像処理サービスを使用するため、制限のない通常のターミナルで`swift test`を実行してください。

プロジェクトは `.player` ファイル（JSON形式）で保存します。素材ファイルは同梱しません。従来の `.geobox.json` や `.json` も読み込めます。

プロジェクト名は読み込み・保存時にファイル名（拡張子を除く）と同期し、アプリ内では直接編集できません。変更する場合は「名前を付けて保存…」を使うか、Finderでファイル名を変更して開き直してください。未保存時は「新規プロジェクト」と表示します。

Finderから開くには、ビルドした `GeoBox Player.app` を一度起動してから、専用拡張子 `.player` のプロジェクトファイルをダブルクリックします。別のアプリで開かれる場合は、`.player` ファイルの「情報を見る」→「このアプリケーションで開く」でGeoBox Playerを指定してください。既存の `.json`・`.geobox.json` プロジェクトは、拡張子を `.player` に変更すれば同様に開けます（内容はJSONのままです）。`.json` 全般のファイル関連付けは登録しません。拡張子を変更せずに使う場合は、アプリ内の「プロジェクトを開く…」から選択してください。
起動時・プロジェクト読込時は、現在時刻の予定に合わせて素材とループ位置を計算し、動画・音声は該当位置から自動再生します。プレイリストの開始予定から次の切替・終了予定までループ再生します。

「スケジューラ設定」は今日から7日間の週表示で開きます。「日」表示、前後の移動、「今日」への復帰に対応します。ドロップ位置は15分単位、初期の予定時間は1時間です。空き時間をダブルクリックすると、その日時で予定の追加画面が開きます。予定の上端・下端をドラッグすると、開始・終了時刻を15分単位で調整できます（最短15分、最長7日）。ドラッグ中は予定の長さと時刻を表示し、確定時に1回の変更として記録します。繰り返し予定の長さ変更にも適用範囲の選択が表示されます。予定をクリックすると正確な日時・フェードを編集でき、別の日時へのドラッグで移動できます。「毎日」「毎週」の繰り返しも指定できます。繰り返し予定の保存・移動・削除時は「すべての予定」「これ以降のすべての予定」「この予定のみ」から適用範囲を選びます。「この予定のみ」はその日の例外として保存し、「これ以降」は選んだ日からシリーズを分割して過去の予定を保ちます。シリーズ全体／これ以降への変更では、対象範囲の個別変更にも新しい設定を適用し、個別に削除済みの日は除外を保ちます。

映像と音声の予定は各日の左右に分けて表示します。同じ系統で予定が重なる場合は開始日時が遅い予定を優先し、同時刻では保存した予定IDの順で決定します。終了時刻に終了フェードを開始し、その時間を過ぎると停止します。重なっていた予定がまだ続いていれば、その予定の経過位置へ戻ります。日時・フェードはプロジェクトファイルに保存され、取り消し・やり直しと画面ロックにも対応します。

プロジェクト設定のデフォルトプレイリスト・開始／終了時刻・開始／終了フェード、プレイリストの開始時刻はカレンダーへ統合しました。旧ファイルの毎日時刻設定は、読み込み時に毎日のカレンダー予定へ移行します。新規プロジェクトは予定なしで始まります。

プレイリスト全体の開始・終了フェードは、スケジューラの予定追加・編集画面でのみ設定します。プレイリスト設定には全体フェードの編集欄を設けず、旧ファイルに残るプレイリスト全体フェード値もカレンダー再生には重ねて適用しません。手動再生には全体フェードを付けず、トラック間フェードは引き続きプレイリストの「トラック間の再生設定」で指定します。

サイドバー、プレイリスト・トラック行、操作ボタン、設定入力欄には、ポインターを重ねると背景や枠が変わるホバー表示があります。カレンダーでは空き時間に追加先の時刻、予定の上下端に調整位置を表示します。無効な操作は強調せず、macOSの「視差効果を減らす」が有効な場合はホバーのアニメーションを省略します。

予定の中央部分を上下にドラッグすると、長さを保ったまま開始・終了時刻を15分単位で移動できます（開始時刻はその日の00:00〜23:45）。上下端のドラッグは長さの調整、予定右下の矢印のドラッグは別の日への移動です。繰り返し予定はドラッグ終了後に適用範囲を選び、キャンセルすると変更しません。移動は取り消し・やり直しに対応します。

音声付き動画をカレンダーから再生する場合、動画内音声は映像予定の開始・終了とフェードに連動します。独立した音声プレイリストの予定がなくても出音します。状態欄には「動画内音声（再生中）」と表示します。映像プレイリストのミュート、トラック音量、独立音声プレイリストの再生中の抑制は引き続き適用します。動画内音声にもプロジェクト設定の音声出力先を使用し、機器が未接続の場合は再接続を待ちます。

プレイリスト全体の再生ボタンは、左の一覧・プレイリスト設定画面ともに設けません。プレイリストの再生はスケジューラで指定し、素材の手動確認にはトラック行の再生ボタンを使います。
