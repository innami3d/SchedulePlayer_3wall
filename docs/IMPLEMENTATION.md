# 実装・検証記録

2026年10月31日。初期実装 v0.1。

## 構成

- `PlayerCore`：JSON保存モデル、値の検証、単一プレイリストの状態遷移、日次スケジュール。フレームと独立した単調時刻でフェードを計算する。
- `PlayerStore`：編集、Undo/Redo、コピー・Cut・複製、相対パス、明示保存、前回のプロジェクトの復元。ロックはUIだけでなく編集メソッドでも判定する。
- `MediaLibrary`：参照パスの重複排除、2秒ごとの更新時刻・サイズ確認による再読み込み、AVURLAssetのメタデータ事前読み込み、画像のデコードキャッシュ（上限256 MB）。動画全体はメモリへ展開しない。
- `PlaybackEngine`：映像・音声にAVPlayerを1つずつ持ち、トラック・プレイリスト・プロジェクトの各フェードを合成する。画像表示時間と動画・音声の末尾を監視し、ループする。
- `OutputDevices` / `VideoOutput`：CoreGraphicsによる4Kモードとリフレッシュレートの選択、別ウインドウへの映像送出、CoreAudio UIDによる音声出力先の指定。終了時に元の画面モードへ戻す。
- UI：SwiftUI + AppKit。右クリック／二本指クリックはネイティブNSMenuを利用する。Deleteと編集ショートカットは文字入力中には横取りしない。

出力APIはAppleの[ディスプレイモード切り替え](https://developer.apple.com/documentation/coregraphics/cgdisplaysetdisplaymode(_:_:_:))と[AVPlayer音声出力先](https://developer.apple.com/documentation/avfoundation/avplayer/audiooutputdeviceuniqueid)に基づく。

## 初期実装で選んだ運用ルール

要件書で未確定だった以下は、初期実装ではこのように動作する。

- 対応OSはmacOS 14以降。ビルド時の検証環境はApple Silicon、Swift 6.2.1／Xcode 26.1.1。
- 4Kは3840×2160または4096×2160の利用可能モードから選ぶ。解像度自体を自由入力する設定は持たない。
- リフレッシュレートは接続先が列挙する4Kモードから選ぶ。対応モードがなければ送出を開始せずエラーにする。画面モードと音声デバイスの変更は出力開始時に適用する。
- プロジェクトはJSON形式。拡張子は`*.player`（内容はJSON）。従来の`*.geobox.json`も読み込める。通常保存（⌘S）は拡張子を問わず既存ファイルへ上書きし、新規保存・名前を付けて保存では`.player`を使用する。プロジェクトと同じフォルダ配下の素材は相対パス、外部素材は絶対パスで保存する。素材実体はコピーしない。
- 前回保存・開いたプロジェクトを次回起動時に復元する。起動・プロジェクト読込時は直近の終了予定から現在時刻までの予定を判定し、予定の切替とプレイリストのループから素材・再生位置を復元して自動再生する。素材準備完了時に再計算する。プレイリスト自身の開始予定でも出力を開始し、次の切替または出力終了予定までループする。
- 時刻はMacのローカル時刻に従い、日付なしで毎日適用する。夜間をまたぐ時間帯も扱う。同じ時刻のイベントは全体終了 → 全体開始 → 個別プレイリストの順で優先する。
- 24時間以内のタイマー停止・スリープ復帰は通過した予定を時刻順に処理する。24時間を超えた場合は、起動時と同じ予定の再構成で現在の素材・再生位置へ合わせる。
- 再生中と同じプレイリストへの再要求は通常無視する。フェード中の再要求は、同じ対象でも最新要求として先頭から開始する。
- 映像出力の終了時には動画内音声も終了する。音声出力全体の終了時は、映像を継続しつつ動画内音声を消音する。
- 手動で映像プレイリストを開始したときは、停止中の音声出力全体も開始し、必要なら動画内音声を出せる状態にする。
- トラックの指定時間／ファイル尺にトラック間フェードを含める。短い素材ではIN・OUTをそれぞれ尺の半分以下へ制限する。
- 再生中のトラックを並べ替えても現在の素材は継続し、その新しい位置の次へ進む。再生中トラックの削除はその位置の次の素材へ進む。全トラック削除・プレイリスト削除は再生を止める。
- 素材パスと表示時間の変更は次にそのトラックを開始するときに反映する。音量・ミュートは再生中も反映する。
- 空プレイリストと読み込めない素材は開始せず、状態とエラーを表示する。事前読み込み中の開始要求は準備完了まで待つ。
- ロックはアプリ内の誤操作防止。起動時は解除状態、解除認証は付けない。保存していない変更があるまま終了する際は保存確認を行う。
- アプリ終了時も全体終了フェードを待ってから終了する。出力していない場合は直ちに終了する。
- Cutした内容はアプリ内クリップボードに保持する。Undoでも戻せる。複製は現在のクリップボードを変更しない。保存成功時は相対パスの基準の変更に備えてUndo履歴を区切る。

## 残る実機検証

- GeoBoxを接続した4K送出、各リフレッシュレートの信号、外部音声インターフェースへの実出音。
- 4K素材・長時間運転・切り替え時のフレーム精度と負荷。
- H.265／HEVC、その他ProRes各種、MP4／MOV内の全プロファイル・色深度・チャンネル構成の素材別検証。
- 音声／映像デバイス切断・再接続とスリープ復帰の実機動作。

一般的な動画コーデック全対応という要件に対し、現時点の再生バックエンドはAVFoundationであり、全コーデックの検証完了を意味しない。再生できない素材は理由を表示する。配布用のDeveloper ID署名・公証は未実施で、生成する.appはローカル用のアドホック署名。

## 出力機器の自動再接続（2026年10月31日）

- プロジェクトにディスプレイのUUIDと音声機器UIDを保存。起動・プロジェクト再読込・機器の再接続時に同じ機器を自動選択する。ディスプレイ番号が変わってもUUIDで照合し、名前が同じ別機器へは切り替えない。
- 旧プロジェクトは、保存済みディスプレイ番号の機器が接続されている際にUUIDを補完する。補完後はプロジェクトを保存する。未接続の旧機器については一度出力先を選び直す必要がある。
- 約2秒ごとに接続を確認。再生中の切断では再生の進行を維持し、同じ機器が戻ったら現在位置の送出を復旧する。終了操作・終了時刻後は再開しない。アプリ起動時は現在時刻のスケジュールに追従して再生する。
- 指定音声機器がない間は両AVPlayerをミュートし、システム音声出力へのフォールバックを防ぐ。復帰時は両方へ保存済みUIDを再適用する。
- 未接続の出力先は設定画面に名前と再接続待ち状態を表示する。再生中の待ち状態は下部ステータスにも表示する。
- UUID照合・番号再利用・旧形式の読込と保存の自動テストを追加。実際のHDMI／USB機器の抜き差し検証は未実施。

識別API：[Apple CGDisplayCreateUUIDFromDisplayID](https://developer.apple.com/documentation/colorsync/cgdisplaycreateuuidfromdisplayid(_:))。

### 保存形式・起動時の時刻追従

- `.player`はJSON形式の単一ファイル。素材は従来どおり参照のみで、同梱しない。Finderの関連付けに専用UTIを登録する。
- 起動時とプロジェクトを開いた際に、映像／音声を独立して復元する。日跨ぎ、同時刻の優先順位、切替時の旧プレイリストのフェードアウト時間を考慮する。
- 画像は表示時間、動画／音声は事前取得した実尺でループ位置を算出する。AVPlayerの準備後にシークし、完了してから再生する。
- 起動前の手動再生・手動停止履歴は復元せず、保存された予定を基準にする。出力先が未接続でも内部の再生を進め、再接続を待つ。
- 24時間を超えるスリープ後も同じ計算で現在位置へ追従する。保存成功時にUndo／Redoを消去する既存仕様は維持する。

### 出力先未設定時のプレビュー

- 映像出力先が未設定でも、手動再生・出力開始・時刻指定・起動時復元で内部の再生と送出プレビューを実行する。ステータスは「プレビューのみ」とする。
- 指定した映像／音声機器が未接続の場合も再生を継続し、再接続を待つ。音声機器が見つからない場合は両プレイヤーを即座にミュートする。
- 音声出力先の未指定は従来どおりシステムのデフォルトを使用する。

- プレイリストの開始時刻は出力開始の独立した予定として扱う。例：13:58に「aa」、17:00にデフォルト再生、22:00に終了。14:15の起動時は「aa」の13:58からの経過時間で再開する。直近の終了予定より前の再生は引き継がないが、その後に開始予定があれば再び開始する。
